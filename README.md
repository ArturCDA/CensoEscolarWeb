## Repositório dos dados

Os dados utilizados nesta aplicação foram extraídos dos microdados do Censo Escolar 2025, referentes às Instituições de Ensino da Paraíba.

O projeto responsável pela extração e geração do arquivo JSON está disponível no seguinte repositório:

[ CensoEscolarDataApp — Repositório dos dados](https://github.com/ArturCDA/CensoEscolarDataApp)

O arquivo JSON gerado é utilizado pela aplicação web para apresentar o ranking das 10 instituições de ensino com maior número de matrículas na educação básica.
